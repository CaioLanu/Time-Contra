# Capacidade de interação (INTR)

Como o produto se comporta nas telas em que é usado.

## NFR-INTR-01 — Uso no celular

O sistema deve exibir todas as telas em 390 px de largura sem rolagem horizontal.

| Attribute | Value |
| --- | --- |
| Rationale | Gestores e locatários usam o app pelo celular |
| Source | Stakeholder, entrevista de 2026-10-20 |
| Priority | Must |
| Status | approved |
| Milestone | M1 |
| Since | v1.0.0 |

**Acceptance criteria**
- **NFR-INTR-01.1** — Given qualquer tela, when ela é aberta em 390 px de largura, then a rolagem horizontal da página é de 0 px.
