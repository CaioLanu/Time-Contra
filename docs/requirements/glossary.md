# Glossário

| Termo | Significado |
| --- | --- |
| Anúncio | A página pública de um campo, vista pelos locatários na busca. |
| Campeonato | Uma série de partidas entre times, disputada em um campo. |
| Campo | Um campo de futebol oferecido para aluguel por um gestor. |
| Comissão | O percentual de cada aluguel que fica com a plataforma. |
| Estrutura | O que o campo oferece além do gramado: arquibancada, bar, vestiário. |
| Gestor | O perfil de quem administra campos no Time-Contra. |
| Horário | Um intervalo de data e hora em que um campo pode ser alugado. |
| Locatário | O perfil de quem busca e aluga campos. |
| Reserva | O aluguel de um horário de um campo por um locatário. |
| Tipo de campo | A categoria do campo, como society ou futsal; o catálogo é definido na spec. |
| Vaga | Um lugar para um time em um campeonato criado pelo gestor. |
| Visualização | Uma abertura do anúncio de um campo por um locatário. |
| Zona | Uma região da cidade, maior que um bairro, usada para filtrar o mapa. |
