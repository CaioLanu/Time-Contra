# Visualizações (ANL)

A audiência do anúncio de cada campo.

## FR-ANL-01 — Contar visualizações do anúncio

> Como gestor, quero saber quantas vezes o anúncio do meu campo foi visto, para avaliar o alcance dele.

O sistema deve exibir ao gestor o número de visualizações do anúncio de cada campo seu.

| Attribute | Value |
| --- | --- |
| Rationale | O gestor acompanha o interesse pelo campo |
| Source | Stakeholder, entrevista de 2026-10-20 |
| Priority | Could |
| Status | approved |
| Milestone | M1 |
| Since | v1.0.0 |

**Acceptance criteria**
- **FR-ANL-01.1** — Given um anúncio com N visualizações, when um locatário o abre, then o gestor passa a ver N + 1 visualizações.
