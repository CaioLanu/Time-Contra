# Design

As telas são desenhadas no Figma. Cada tela documentada aqui tem a imagem exportada do Figma e a especificação
dela, primeiro na largura do celular e depois no desktop.

| Pasta | O que tem |
| --- | --- |
| [Marca](brand/README.md) | Descrição da marca, logo e demais peças |
| [Tokens](tokens.md) | Cores, tipografia, espaçamento, raios e sombras, no tema claro e no escuro |

As telas entram em `pages/<feature>/<tela>.md` conforme cada feature é especificada. O link do arquivo do Figma
entra aqui quando o arquivo existir.
