# Roadmap

O status ao vivo fica no [GitHub Project](https://github.com/users/CaioLanu/projects/1) e nos
[milestones](https://github.com/CaioLanu/Time-Contra/milestones).

## M1 — Protótipo

O gestor anuncia o campo e controla a agenda, e o locatário encontra no mapa e reserva. GitHub Milestone:
[M1 — Protótipo](https://github.com/CaioLanu/Time-Contra/milestone/1).

| Épico | Issue | Cobre |
| --- | --- | --- |
| Contas e acesso | [#1](https://github.com/CaioLanu/Time-Contra/issues/1) | FR-ACC-01, FR-ACC-02, FR-ACC-03, BR-01, NFR-INTR-01 |
| Anúncio de campos | [#2](https://github.com/CaioLanu/Time-Contra/issues/2) | FR-FLD-01, FR-FLD-02, FR-FLD-03, FR-FLD-04, NFR-SEC-01 |
| Busca no mapa | [#3](https://github.com/CaioLanu/Time-Contra/issues/3) | FR-SRC-01, FR-SRC-02, FR-SRC-03, FR-SRC-04, FR-SRC-05 |
| Reservas e agenda | [#5](https://github.com/CaioLanu/Time-Contra/issues/5) | FR-BKG-01, FR-BKG-02, FR-BKG-03, FR-PAY-01, BR-03, BR-04 |
| Visualizações do anúncio | [#4](https://github.com/CaioLanu/Time-Contra/issues/4) | FR-ANL-01 |

Os épicos são construídos nessa ordem, cada um depois do anterior. O épico de visualizações é Could e sai do
M1 se faltar tempo.

O M2 (pagamento pelo app e campeonatos) é dividido em épicos quando o M1 fechar.
